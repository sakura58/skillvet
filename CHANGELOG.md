# Changelog

## 0.1.0

First release.

- Frontmatter parsing without third-party dependencies
- Checks for name, description, directory agreement and context budget
- Reference checks for relative links and bundled files
- Supply-chain checks: remote scripts, credential reads, destructive deletes,
  prompt injection, exfiltration and hardcoded credentials
- `text`, `json` and `github` output formats
- GitHub Actions composite action and pre-commit hook
